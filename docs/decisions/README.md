# Decisions

Amber's own architecture and product decisions, in the handbook's format: one file per decision,
`NNNN-short-slug.md`, numbered in order and never renumbered. A decision that's replaced isn't
edited or deleted; a new file says what it supersedes, and the old one's Status points to it.
Decisions that affect more than one of Itrium's projects belong in the handbook instead.

```markdown
# NNNN. Title

Status: proposed | accepted | superseded by NNNN

## Context

## Decision

## Consequences
```
